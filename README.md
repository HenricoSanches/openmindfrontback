# 🧠 OpenMind

Plataforma de apoio psicológico universitário desenvolvida com React, TypeScript e Supabase.

---

# 🚀 Tecnologias

- React
- TypeScript
- TailwindCSS
- Supabase
- PostgreSQL
- TanStack Router

---

# 📦 Instalação

## Clone o projeto

```bash
git clone https://github.com/HenricoSanches/openmindfrontback.git
```

---

## Entre na pasta

```bash
cd openmindfrontback
```

---

## Instale as dependências

```bash
npm install
```

---
